## 四、BUG 与「安全事件」区分

- **功能 BUG**：消息、线路、WS（上表 B1～B5、B7）— 影响可用性。  
- **安全事件**：SSH 凭据滥用、全库导出、未授权 root（R-P0）— 影响机密性与完整性。  
- **合规风险**：采集通讯录/曝光/TG（R-P1）— 属产品设计，需法务与隐私评估。
