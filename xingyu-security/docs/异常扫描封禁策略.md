# 星语异常扫描封禁策略

## 1. 目标

在**不误伤 CDN 回源与 App 正常请求**的前提下，对互联网扫描、撞库、敏感路径探测进行**分层封禁**。

## 2. 分层模型

```
                    互联网扫描/撞库
                           │
         ┌─────────────────┼─────────────────┐
         ▼                 ▼                 ▼
   [L1 Nginx]        [L2 fail2ban]      [L3 UFW/SSH]
   444 丢弃 URI      封 IP 30天~永久     17603 白名单
   不记业务日志      sshd + 爬虫 jail     仅公钥登录
```

| 层级 | 组件 | 作用 | 误伤风险 |
|------|------|------|----------|
| L1 | `01-hz-anti-crawler-map.conf` | 已知恶意 URI/UA 直接 444 | 中（曾误伤空 UA CDN） |
| L2 | `fail2ban` hz-nginx-crawler + sshd | 重复探测 IP 封禁 | 低（配 ignoreip） |
| L3 | `ufw` + `sshd` | SSH 仅白名单 IP + 公钥 | 低（运维 IP 需登记） |

## 3. 封禁对象（异常扫描定义）

### 3.1 HTTP（Nginx → 444 或计入 fail2ban）

- 路径：`.env`、`.git`、`wp-*`、`phpmyadmin`、`mysqldump.sql`、`/actuator`（非业务）、`*.php`（本栈无 PHP）、`xxing.png` 等扫描特征。
- User-Agent：空 UA **仅**在命中「探测路径」时封；**不**对 `/api/`、`/apiBiz/`、`/im`、`/file/` 空 UA 一律 444（避免 CDN 502）。
- 明确封禁 UA 关键词：`Nmap`、`sqlmap`、`masscan`、`Keydrop`、`onlyscans`、`GPTBot`（按需）、`Censys` 等。

### 3.2 SSH（fail2ban sshd）

- `Failed password` / `Invalid user` 连续 **5 次 / 10 分钟** → 封 **24 小时**（可改为 7d）。
- **禁止**密码登录后，撞库成功率应趋近 0；fail2ban 仍保留降噪。

### 3.3 白名单（必须配置）

在 `jail.local` 或 `ignoreip` 中永久加入：

- 运维 SSH IP（如 `113.5.87.189`）
- CDN 回源网段（HZ 记录示例：`163.223.146.0/24`，以当前 CDN 为准）
- 本机 `127.0.0.1`

## 4. 与历史 HZ 变更的兼容

| 历史问题 | 本策略做法 |
|----------|------------|
| CDN 空 UA 导致 502 | `$hz_block_uri` 与 `$hz_block_ua` 分离；业务路径不依赖 UA |
| fail2ban 封 CDN | `ignoreip` 维护回源段；解封流程写进 runbook |
| 防爬过严 | 不封 `Dart/`、`okhttp`、`IM-` 等 App UA |

## 6. 验证清单

- [ ] `curl -H 'Host: jjk5.bobobo.site' http://127.0.0.1/api/line/ping` → 200  
- [ ] `curl http://127.0.0.1/.env -H 'Host: jjk5.bobobo.site'` → 444  
- [ ] `fail2ban-client status hz-nginx-crawler` → enabled  
- [ ] `sshd -T | grep passwordauthentication` → no  
- [ ] `ufw status | grep 17603` → 仅运维 IP  

## 7. 运营 Runbook

1. **客户无法登录**：先查 CDN 回源 IP 是否被封 → `fail2ban-client status hz-nginx-crawler` → `unbanip <ip>`。  
2. **运维连不上 SSH**：控制台/VNC 检查 `ufw` 与 `authorized_keys`。  
3. **每周**：`zgrep 'Accepted password' /var/log/auth.log*` 应为空；复查 `/tmp/*.sql.gz`。
